# Final submission checklist

1. Run:
   `uvicorn main:app --reload`
2. Open:
   `http://localhost:8000/docs`
3. Test all CRUD operations in Swagger.
4. Run the curl commands from README.
5. Take a screenshot of `/docs`.
6. Put the screenshot at `docs/swagger-screenshot.png`.
7. Create a public GitHub repository.
8. Make the required meaningful stage commits.
9. Push the repository.
10. Submit the GitHub repository URL.
